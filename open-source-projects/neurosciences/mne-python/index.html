MNE-Python

Open-source Python package for exploring, visualizing, and analyzing human neurophysiological data (MEG, EEG, sEEG, ECoG, NIRS, and more).

Maintainer · since March 2023 GitHub Documentation PyPI

MNE-Python is one of the 4 major M/EEG analysis packages, alongside its 3 MATLAB counterparts, FieldTrip, Brainstorm and EEGLAB. After using it and contributing for several years, I joined the maintainers in March 2023.
